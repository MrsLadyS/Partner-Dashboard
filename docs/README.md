# Documentation Hub

This folder contains planning and implementation documentation for features that are **to be built**.

## Current Workstreams

- `cra-support-module/` - Community Engagement Command Center CRA Support Module planning set.

## Why this exists

The dashboard has evolved quickly through iterative UI updates. This documentation hub creates a stable source of truth for:

- scope boundaries and non-goals
- architecture and data model decisions
- phased implementation planning
- compliance and reviewer expectations
- unresolved questions and risks

Each document should be treated as a living artifact and updated as decisions are made.
